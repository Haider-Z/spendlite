# SpendLite

A personal expense tracker built with FastAPI, SQLite,
SQLAlchemy, HTML, CSS and JavaScript.

## Features

- Add expenses
- View all expenses
- Delete expenses
- Filter by category
- View spending summary
- API validation
- Automated tests

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- HTML, CSS and JavaScript
- Pytest
